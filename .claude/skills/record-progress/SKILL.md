# 진행상황 기록 (PlatformGLOverlay)

하루 작업을 마칠 때 이 스킬로 **현재 진행상황을 문서로 남기고, 커밋·push까지** 끝낸다.

## 절차

1. **진행상황 정리** — 이번 작업으로 무엇이 완료됐고, 무엇이 진행 중이며, 다음에 무엇을
   할지 파악한다. 저장소 상태(`git status`, 최근 커밋, 테스트 통과 여부)를 근거로 삼는다.

2. **`docs/progress/CURRENT_PROGRESS.md` 갱신** — 아래 구조로 **덮어쓴다**(이 파일은 항상
   "지금 시점의 현재 상태" 하나만 담는다). 날짜는 절대 날짜로 적는다.

   ```markdown
   # 현재 진행상황 — <YYYY-MM-DD>

   ## 한 줄 요약
   <지금 어디까지 왔는지 한 문장>

   ## 완료
   - <끝난 항목들. 마일스톤/기능 단위로.>

   ## 진행 중 / 다음 할 일
   - <이어서 할 작업. 우선순위 순.>

   ## 핵심 결정·메모
   - <재논의 방지용 확정 결정, 주의점, 알려진 보류 항목.>

   ## 검증 상태
   - <테스트/빌드 통과 현황 (예: golden N개, abi 스모크 등).>
   ```

   - 문서 편집이므로 **doc-writing 스킬 규칙**을 따른다(이력 블록 절제, 요약 우선).
   - `docs/progress/` 디렉토리가 없으면 만든다.

3. **커밋·push** — **git-commit 스킬을 실행**해 커밋과 push를 마무리한다.
   커밋 메시지는 이번 작업의 핵심을 영어 1~3문장으로 요약한다(git-commit 규칙을 따른다).

## 주의

- 이 파일은 누적 로그가 아니라 **현재 스냅샷**이다. 지난 내용을 길게 쌓지 말고 최신 상태로
  갱신한다. (세부 이력이 필요하면 git 로그가 담당한다.)
- 진행상황 요약은 사실 기반으로 적는다 — 테스트가 실패했거나 건너뛴 부분이 있으면 그대로 적는다.
